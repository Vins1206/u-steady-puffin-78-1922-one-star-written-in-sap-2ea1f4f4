## What it does

`main.py` writes one line — a one-star review in the voice of a houseplant
about its human owner — to `/output/entry.txt`. The plant's grievance: it
was repotted into a mug with no drainage, praised as "rustic", and left
sitting in a puddle of its own regrets, photosynthesizing out of spite.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, deterministic: every run writes the same
line, 1–279 characters, UTF-8, a single line.
